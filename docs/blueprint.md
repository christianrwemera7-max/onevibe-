# **App Name**: CyberDoc

## Core Features:

- Secure User Authentication: Users can securely log in using Google, and new users complete a profile with academic details (university, faculty, promotion).
- Document Creation & Formatting: Users input document details (course, professor, title) and raw content. The system supports Markdown and LaTeX syntax for advanced formatting, with controls for font, size, line spacing, and margins.
- Intelligent Formatting Assistant (AI): An AI tool that analyzes document content against academic best practices, providing contextual suggestions to improve structure, clarity, and ensure grammatical correctness before finalization.
- Real-time Document Preview: A live, interactive preview of the document reflects all formatting choices, dynamic pricing, and selected services (like cover page and binding options), displaying a watermark until paid.
- Dynamic Service & Pricing: Offers flexible service selections including digital PDF, black & white printing, or color printing. Additional options for a professional cover page and binding are available, with real-time price calculation based on all choices.
- Credit-Based Transactions: Manages user credit balance, facilitating payments for document services directly from the account and providing a streamlined interface for credit top-ups.
- Document Management & Export: Maintains a history of all created documents, their status (draft/paid), and allows paid documents to be downloaded as a PDF, including applied formatting and options.

## Style Guidelines:

- Primary color: A vibrant yet professional blue (#2563EB), signifying trust and intelligence. (HSL: 215, 90%, 53%)
- Background color: A very light, desaturated blue-gray (#F2F6FA), providing a clean and serene canvas. (HSL: 215, 20%, 97%)
- Accent color: A dynamic aqua-cyan (#26ACC9), used for highlights and calls to action, injecting a modern digital feel. (HSL: 185, 70%, 50%)
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-savvy, and assertive look in titles.
- Body text font: 'Inter' (sans-serif) ensuring excellent legibility and a neutral, professional tone for academic content.
- Code font: 'Source Code Pro' (monospace) for clear display of code snippets or structured technical text within documents.
- Use a consistent set of clean, outline-style icons (like those from Lucide) to maintain clarity and a modern aesthetic throughout the application.
- A modern, spacious, and card-based layout with clear visual hierarchy, ample padding, and softly rounded elements to convey professionalism and ease of use. Content is centrally aligned and responsively structured.
- Subtle and functional micro-animations for state changes, navigation transitions, and interactive elements (e.g., hover effects, button feedback), enhancing user experience without being distracting.
